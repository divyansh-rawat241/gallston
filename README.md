# GallStone AI v6

Dual-detector abdominal-ultrasound gallstone workstation with calibrated
confidence and a distribution-free recall guarantee.

**Status**: patent-grade rebuild in progress. See
[PATENT_GRADE_MASTER_PLAN.md](PATENT_GRADE_MASTER_PLAN.md) for phase tracker
and [docs/CLAIMS.md](docs/CLAIMS.md) for draft patent claims. This README
carries only numbers we can defend from the repo.

---

## What ships

- **Detectors** — YOLOv26L (Ultralytics) + RF-DETR-L (`rfdetr`, DINOv2
  backbone), both trained under Optuna hyperparameter search.
- **Fusion** — Weighted Boxes Fusion (Solovyev 2021) modulated by a
  posterior-acoustic-shadow prior computed from the region immediately
  inferior to each candidate ([src/evaluation/shadow_analyzer.py](src/evaluation/shadow_analyzer.py)).
- **Calibration** — per-detector temperature scaling + post-fusion isotonic
  regression + optional 4-D multivariate binning
  ([src/calibration/](src/calibration/)).
- **Conformal** — split-conformal per-coordinate box expansion (Bonferroni
  over 4 coordinates) + Conformal Risk Control on recall
  ([src/conformal/](src/conformal/)).
- **XAI** — EigenCAM on YOLO + decoder cross-attention on RF-DETR +
  cross-architecture attention-agreement map
  ([src/explainability/](src/explainability/)).
- **Backend** — FastAPI unified API under `/api/*`
  ([api/](api/)).
- **Frontend** — React 19 + TypeScript + Vite + Tailwind, light-theme
  clinical workstation ([frontend_react/](frontend_react/)).

## What does NOT yet ship

- COCO-style mAP numbers on the test set. `calculate_map` currently
  returns per-image mean F1; a `torchmetrics.detection` swap is planned.
- Calibration and conformal artefacts under `production_models/` are
  regenerated by running `scripts/fit_calibration.py` and
  `scripts/fit_conformal.py` locally.
- External-institution validation (blocked on data access).
- Radiologist comparison AUROC / κ (blocked on annotation).

Anything else that reads like a benchmark and is not covered in
[docs/BENCHMARKS.md](docs/BENCHMARKS.md) with a source JSON file is not a
number we claim.

## Real numbers we can currently defend

| Item | Value | Source |
|---|---:|---|
| Best val mAP@50 · YOLOv26L | **0.9598** | `yolo26l_hpo_results.db` (Optuna, 19 trials) |
| Best val mAP@50 · RF-DETR-L | **0.9606** | `rf_detr_large_hpo_results.db` (Optuna, 140 trials) |
| Train / val / test split | 1024 / 368 / 201 | `dataset_final_resplit/split_info.json` (image-level, seed 42 — **not** patient/video-level, see warning below) |
| Polygon labels | 2074 / 774 / 405 rows | `mlruns/phase1_validation.json` |
| Unit tests | 16 / 16 green | `pytest tests/` |

> **Every number above was measured on a leaked split** — see
> [docs/LEAKAGE_AUDIT.md](docs/LEAKAGE_AUDIT.md). In `dataset_final_resplit/`,
> 62% of test images are byte-identical copies of training images and every
> test video also appears in training; the evaluation scripts also reported
> per-image F1 under the name "mAP".
>
> **Use the grouped workflow instead:**
>
> ```bash
> python scripts/build_grouped_split.py --overwrite   # whole videos per split, deduplicated
> python scripts/check_leakage.py --data dataset_grouped   # must print RESULT: clean
> python scripts/train_grouped.py --model both              # COCO-pretrained start, leakage-gated
> python scripts/eval_grouped.py --yolo <best.pt> --rfdetr <best.pth>   # COCO mAP + grouped bootstrap CI
> ```

## Quickstart

Backend:

```bash
pip install -r requirements.txt
uvicorn api.main:app --host 0.0.0.0 --port 8000
```

Frontend:

```bash
cd frontend_react
npm install
npm run dev
```

Visit http://localhost:5174 · API docs at http://localhost:8000/docs.

Regenerate every published number end-to-end (see
[docs/REPRODUCIBILITY.md](docs/REPRODUCIBILITY.md)):

```bash
bash scripts/regenerate_all_numbers.sh
```

Individual steps:

```bash
python scripts/comprehensive_evaluation.py --split test
python scripts/tune_shadow_threshold.py --split val
python scripts/fit_calibration.py --split val
python scripts/fit_conformal.py --calibration-split val --test-split test --alpha 0.05
python scripts/generate_manifest.py
```

## API surface

```
GET  /api/health                        model + artefact readiness
POST /api/upload                        DICOM / JPG / PNG ingest + metadata
GET  /api/upload/{scan_id}              session state
POST /api/predict/{scan_id}             WBF+shadow -> calibrate -> conformal -> verdict
GET  /api/predict/{scan_id}             cached prediction
GET  /api/explain/{scan_id}             YOLO CAM + DETR attention + agreement map
GET  /api/report/{scan_id}              honest structured report (real mm² when DICOM)
GET  /api/metrics                       all pre-computed benchmark reports
GET  /api/metrics/benchmarks|calibration|conformal|shadow_tuning
```

Config via `GALLSTONE_*` env vars — see [api/settings.py](api/settings.py).

## Design principles (non-negotiable)

- **No fake numbers.** Every metric surfaced to the UI or the report is
  either loaded from an on-disk JSON produced by a committed script, or
  rendered as `—`. Fabrications in the previous V5 backend were purged in
  Phase 0.
- **Provenance per field.** Every emitted probability carries a
  `provenance` tag: `raw`, `temperature_scaled`, `isotonic_fusion`,
  `split_conformal_bonferroni`, `crc_recall_bound`, `selective`.
- **Graceful degradation.** Missing calibration or conformal artefacts
  reduce the response, they never break `/predict`.
- **Honest clinical report.** Wall thickness, CBD calibre, and adjacent-
  structure findings are not produced by the model — they are not in the
  report. The disclaimer says so.
